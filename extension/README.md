# OffTracker ブラウザ拡張機能

OffTrackerをブラウザ拡張機能としてインストールして、自動でタブの使用状況を追跡できるようにします。

## 機能

- **自動タブ追跡**: セッション開始時に、アクティブなタブのURLを自動的に記録（1分ごと）
- **手動イベント記録**: ユーザーが手動でイベントを記録することも可能
- **ダッシュボード**: 今日の利用時間、集中時間、脱線回数を表示
- **タイムライン**: 日付ごとのイベント履歴を表示
- **行動ストーリー**: AIによる行動分析（要Cloudflare Functions）

## インストール手順

### Chrome/Edgeの場合

1. **拡張機能フォルダを準備**
   - `extension` フォルダを確認してください
   - 以下のファイルが含まれていることを確認:
     - `manifest.json`
     - `background.js`
     - `popup.html`
     - `style.css`
     - `icon16.png`
     - `icon48.png`
     - `icon128.png`

2. **ブラウザで拡張機能ページを開く**
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`

3. **デベロッパーモードを有効にする**
   - 右上の「デベロッパーモード」スイッチをオンにする

4. **拡張機能を読み込む**
   - 左上の「パッケージ化されていない拡張機能を読み込む」をクリック
   - `extension` フォルダを選択
   - 「読み込む」をクリック

5. **インストール確認**
   - 拡張機能リストに「OffTracker」が表示される
   - ブラウザのツールバーにOffTrackerアイコンが表示される

### Firefoxの場合

1. **拡張機能フォルダを準備**
   - `extension` フォルダを確認してください

2. **ブラウザで拡張機能ページを開く**
   - `about:debugging#/runtime/this-firefox`

3. **一時的なアドオンを読み込む**
   - 「一時的なアドオンを読み込む」をクリック
   - `manifest.json` ファイルを選択

4. **インストール確認**
   - 拡張機能がインストールされる

## 使用方法

### 初回設定

1. **拡張機能をクリック**
   - ブラウザツールバーのOffTrackerアイコンをクリック
   - ポップアップが開く

2. **ログイン**
   - メールアドレスとパスワードを入力
   - 「ログイン」をクリック

### セッション開始

1. **セッション開始ボタンをクリック**
   - ダッシュボードの「セッション開始」をクリック
   - 自動トラッキングが開始される（1分ごとにアクティブタブを記録）

2. **作業中**
   - 通常通りブラウザを使用
   - アクティブタブが自動的に記録される

### セッション終了

1. **セッション終了ボタンをクリック**
   - ダッシュボードの「セッション終了」をクリック
   - 自動トラッキングが停止される

### データ確認

1. **ダッシュボード**
   - 今日の利用時間、集中時間、脱線回数を確認

2. **タイムライン**
   - 日付を選択して「読み込み」をクリック
   - その日のイベント履歴を確認

3. **行動ストーリー**
   - 日付を選択して「ストーリー生成」をクリック
   - AIによる行動分析を表示（要Cloudflare Functions）

## 自動追跡について

- **追跡間隔**: 1分ごとにアクティブタブを記録
- **記録内容**: アプリ名、サービス名、URL、イベントタイプ
- **イベントタイプ**: 自動判定（YouTube/Netflix/Spotifyは「脱線」、その他は「集中」）
- **追跡対象**: アクティブなタブのみ

## 注意事項

- 拡張機能はアクティブなタブのみを追跡します
- プライベートブラウジングでは追跡されません
- データはSupabaseに保存されます
- 自動追跡はセッション開始時のみ有効になります

## トラブルシューティング

### 拡張機能が読み込めない

- `manifest.json` の構文を確認
- ファイルが正しい場所にあるか確認
- ブラウザのバージョンを確認

### 自動追跡が動作しない

- セッションが開始されているか確認
- アクティブタブが存在するか確認
- ブラウザのコンソールでエラーを確認

### ログインできない

- Supabaseの設定を確認
- ネットワーク接続を確認
- メール認証が有効になっているか確認

## アンインストール

### Chrome/Edge

1. `chrome://extensions/` または `edge://extensions/` を開く
2. OffTrackerの「削除」をクリック
3. 確認ダイアログで「削除」をクリック

### Firefox

1. `about:addons` を開く
2. OffTrackerの「削除」をクリック
3. 確認ダイアログで「削除」をクリック

## サポート

問題がある場合は、以下を確認してください:
- ブラウザのコンソール（F12）でエラーメッセージを確認
- Supabaseダッシュボードでデータが保存されているか確認
- 拡張機能の権限が正しく設定されているか確認
