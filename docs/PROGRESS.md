# OffTracker 進捗状況

## プロジェクト概要
PC上の行動履歴を収集・分析し、「何にどれだけ時間を使ったか」だけでなく、「どのような流れで行動し、なぜ集中や脱線が起きたのか」を可視化する行動理解プラットフォーム。

## 具体的な問題

### 🐛 技術的問題

1. **認証エラー**
   - 状況: 「Email not confirmed」エラーが発生
   - 原因: Supabaseのメール確認設定
   - 対応: メール確認を無効化することで解決予定

2. **データ収集機能の欠如**
   - 状況: UIは完成しているが、実際のデータ収集機能がない
   - 影響: デモ・テストができない
   - 対応: ネイティブアプリの実装が必要

3. **Azure AI API未設定**
   - 状況: Functionsの準備はあるがAPIキー未設定
   - 影響: AI機能が使えない
   - 対応: APIキーの取得と設定

### 🎯 製品的問題

1. **ユーザビリティ**
   - 目的設定フローの改善
   - オンボーディングプロセスの追加

2. **機能不足**
   - 手動データ入力機能の追加（拡張機能未使用時）
   - データ編集・削除機能
