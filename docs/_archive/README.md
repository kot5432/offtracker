# アーカイブ

このフォルダーには、過去の計画・調査・画面仕様を履歴として保管しています。内容は削除していません。

- `root-plans/`: ルート直下にあった旧計画・コミット計画
- `status-reports/`: 過去時点の状態報告・調査結果
- `legacy-docs/`: 旧Web版や旧データ形式に関する資料
- それ以外の文書: 過去のフェーズ計画や調査記録

現行の作業判断はルートの `MASTER_DEVELOPMENT_PLAN.md`、製品方針は `docs/PRODUCT.md` と `docs/MVP_DEFINITION.md` を参照してください。アーカイブ内の記述は当時の記録であり、現在の実装や計画を示すとは限りません。
