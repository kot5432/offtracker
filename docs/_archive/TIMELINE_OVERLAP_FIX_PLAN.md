# Timeline重なり問題修正プラン

## 問題
短時間で複数のアプリを行ったり来たりしているため、同じアプリのイベントが重なって見にくい

## 疑似データの分析
4番目のセッション（勉強）のイベント：
1. 22:30-22:40: PDF Viewer (10分)
2. 22:40-22:45: Microsoft Edge (5分)
3. 22:45-22:50: PDF Viewer (5分)
4. 22:50-22:55: Microsoft Edge (5分)
5. 22:55-23:00: PDF Viewer (5分)

PDF ViewerとMicrosoft Edgeが短時間で交互に切り替わっているため、同じアプリのイベントが複数存在し、横棒が重なる可能性がある。

## 解決策

### 推奨: 同じアプリの連続イベントを結合
- 同じアプリの連続イベントを1つのイベントに結合
- 結合したイベントの開始時間は最初のイベントの開始時間
- 結合したイベントの終了時間は最後のイベントの終了時間
- 結合したイベントの持続時間は合計時間

### 表示例（結合前）
```
PDF Viewer: [10分]       [5分]       [5分]
Edge:              [5分]       [5分]
```

### 表示例（結合後）
```
PDF Viewer: [20分]
Edge:              [10分]
```

## 実装手順
1. イベントをアプリ/サービスごとにグループ化
2. 同じアプリの連続イベントを結合
3. 各アプリ/サービスを行として表示
4. 行ラベルを左側に配置（アプリ/サービス名）
5. 各アプリ/サービスのイベントを横方向に配置
6. 時間軸を下部に配置

5. 時間の流れが見やすいか確認
