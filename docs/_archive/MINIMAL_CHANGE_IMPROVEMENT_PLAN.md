# 最小限の変更による改善プラン

## 検証結果から明らかになった問題
- Timelineが表示されていなかった（画面遷移の問題）
- 検証項目がプロセス全体を評価していない
- 「次の行動を考えられたか」はTimeline画面だけでは満たせない

## 改善方針
- 現在の画面遷移を維持（ある程度の画面遷移はよい）
- 各画面の役割を明確にする
- 最小限の変更で改善する

## 各画面の役割（明確化）

### Home画面
- 目的を設定する
- 記録を開始/終了する

### Result画面
- 結果を記録する（達成度、できたこと、できなかったこと）
- Timelineへの遷移を提供

### Timeline画面
- 行動を振り返る（行動を把握する）
- 「なぜ」を考えるための材料を提供する
- **振り返り支援を強化**

### Reflection画面
- 「なぜできなかった？」を考える
- **次の行動を考えるためのガイダンスを追加**
- Timelineへの遷移を提供

### Pattern画面
- 過去の記録と比較（将来的な機能）
- 現在は最小限の機能

## 実装手順

### 改善1: Timeline画面の表示を修正
- Timeline画面への遷移を機能させる
- Timeline画面が正しく表示されているか確認
- イベントデータが正しく表示されているか確認

### 改善2: Timeline画面の振り返り支援を強化
- 振り返りのヒントを改善
- 「なぜ」を考えるための質問を追加
- 次の行動を考えるためのヒントを追加

### 改善3: Reflection画面の改善
- 次の行動を考えるための質問を追加
- Timelineへの遷移を提供

## ファイルを変更
- `desktop/ui/timeline.html` - Timeline画面
- `desktop/ui/reflection.html` - Reflection画面

## 検証手順
1. Timeline画面の表示を確認
2. 振り返り支援を確認
3. 実際に使用して検証
4. 検証結果を記録
