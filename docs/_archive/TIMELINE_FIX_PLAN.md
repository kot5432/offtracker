# TimelineとResult画面の改善プラン

## 検証結果の分析

### 検証項目
- ① 行動を把握できたか: ×（把握できていない。どこでどう示していたかがわからない）
- ② 目的とのズレが分かったか: ×（ずれを考えるような機会がなかった）
- ③ 結果が分かったか: △（結局何を伝えたいのかがよくわからなかった）
- ④ 「なぜ」が考えられたか: △（推測の部分を見せてからであればなぜの部分が考えられる）
- ⑤ 振り返りは負担ではなかったか: ○
- ⑥ 次の行動を考えられたか: ×（考えるきっかけがなかった）

### 特に確認したい点
- **Timelineが表示されていない（terminalが表示されていなかった）**
- 画面遷移がちゃんとできているか確認が必要

### 改善が必要な点
- **結果と達成度の二つが表示されているがどのような意味があるのかがわからない**
- **できた場合も原因を考えるのか？できなかったと思いますかと聞かれているがどのような場合に原因を考えるのか**
- Timelineが見れていないように感じる

## 問題の特定

### 問題1: Timelineが表示されていない
- ユーザーが「terminalが表示されていなかった」と言っている
- Timeline画面への遷移が機能していない可能性
- Timeline画面にアクセスできているが、イベントが表示されていない可能性

### 問題2: Result画面の「結果」と「達成度」の区別が不明確
- 「結果」セクションで達成度を選択させる
- 「達成度」という言葉と「結果」という言葉が混在
- ユーザーがどのような場合に原因を考えるのか不明

## 改善プラン

### 改善1: Timeline画面の表示を修正
1. Timeline画面への遷移を確認
2. Timeline画面が正しく表示されているか確認
3. イベントデータが正しく読み込まれているか確認
4. イベントが正しく表示されているか確認

### 改善2: Result画面の改善
1. 「結果」セクションを「達成度」セクションに変更
2. 「達成度」を選択するUIを明確にする
3. 原因を考えるタイミングを明確にする
   - 未完了の場合のみ原因を考えるようにする
   - または、すべての達成度で原因を考えるようにする

### 改善3: Timelineへの遷移を明確にする
1. Result画面からTimelineへの遷移を明確にする
2. Timeline画面を開くボタンを追加
3. Timeline画面へのリンクを強調

## ファイルを変更
- `desktop/ui/timeline.html` - Timeline画面
- `desktop/ui/result.html` - Result画面

## 検証手順
1. Timeline画面への遷移を確認
2. Timeline画面が正しく表示されているか確認
3. Result画面の「達成度」セクションを確認
4. 原因を考えるタイミングを確認
