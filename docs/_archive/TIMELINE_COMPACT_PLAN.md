# Timeline見やすさ改善プラン

## 問題
- 縦に長く記録が並んでいる
- 見にくい

## 改善案

### 方案1: コンパクトなタイムライン
- 各イベントの高さを下げる
- 行間を狭くする
- より多くのイベントを表示

### 方案2: グループ化表示
- 同じアプリの連続使用をグループ化
- 合計時間を表示
- 詳細を省略

### 方案3: ページネーション
- 複数ページに分割
- ページ送り機能

### 方案4: 折りたたみ表示
- 各イベントを折りたたみ
- クリックで詳細を表示

## 推奨
**方案1: コンパクトなタイムライン**
- シンプルで実装しやすい
- 見やすさが大幅に改善

## 実装内容
- タイムラインイベントの高さを下げる
- 行間を狭くする
- より多くのイベントを表示
