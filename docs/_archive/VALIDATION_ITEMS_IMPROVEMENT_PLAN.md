# 検証項目改善プラン

## 現在の検証項目の問題

### 検証結果
- ① 行動を把握できたか: ×（把握できていない。どこでどう示していたかがわからない）
- ② 目的とのズレが分かったか: ×（ずれを考えるような機会がなかった）
- ③ 結果が分かったか: △（結局何を伝えたいのかがよくわからなかった）
- ④ 「なぜ」が考えられたか: △（推測の部分を見せてからであればなぜの部分が考えられる）
- ⑤ 振り返りは負担ではなかったか: ○
- ⑥ 次の行動を考えられたか: ×（考えるきっかけがなかった）

### 問題の分析
1. **Timelineが表示されていなかった**: 画面遷移の問題でTimelineにアクセスできていなかった
2. **検証項目がプロセス全体を評価していない**: Timeline画面だけの機能を評価しているが、振り返りプロセス全体を評価すべき
3. **「次の行動を考えられたか」はTimeline画面だけでは満たせない**: Reflection画面と組み合わせる必要がある

## 改善案

### プロセス全体の検証項目に変更

#### 画面遷移
Home → 記録開始 → 記録中 → 記録終了 → Result → Timeline → Reflection → Pattern

#### 検証項目（プロセス全体）

**① 行動を把握できたか**
- Timeline画面で「自分が何をしていたか」が分かるか
- 時間の流れが見えるか
- どのようなアプリを使っていたかが分かるか

**② 目的とのズレが分かったか**
- Timeline画面で「どこで目的から外れたか」が分かるか
- 色分けが役に立ったか
- 振り返りのヒントが役に立ったか

**③ 結果が分かったか**
- Result画面で「どの程度達成できたか」が分かるか
- 「達成度」の選択が明確か
- 目標時間と実際時間の比較が分かるか

**④ 「なぜ」が考えられたか**
- Timeline画面を見て「なぜ」を考えるための材料が得られたか
- Reflection画面で「なぜ」を考えることができたか
- TimelineとReflectionの組み合わせで「なぜ」が理解できたか

**⑤ 振り返りは負担ではなかったか**
- プロセス全体（Result → Timeline → Reflection）の負担はどうか
- 各画面の入力が簡単か
- 思考を促すヒントが役に立ったか

**⑥ 次の行動を考えられたか**
- Reflection画面で「次回どうしたいか」を考えることができたか
- Timeline画面を見て「次回どうしたいか」を考えるきっかけがあったか
- 振り返り全体を通じて「次の行動」を考えることができたか

## 実装手順

1. **画面遷移の確認**
   - Result → Timeline → Reflectionの遷移が機能しているか確認
   - Timelineが正しく表示されているか確認

2. **検証項目の改善**
   - プロセス全体の検証項目に変更
   - 検証ガイドを更新

3. **Timeline画面の改善**
   - Timeline画面のヒントを改善
   - 振り返りを促す機能を追加

## ファイルを変更
- `TIMELINE_VALIDATION_GUIDE.md` - 検証ガイド
- `TIMELINE_VALIDATION_EXAMPLE.md` - 検証結果の例

## 検証手順
1. 画面遷移を確認
2. 検証項目に従って実際に使用して検証
3. 検証結果を記録
