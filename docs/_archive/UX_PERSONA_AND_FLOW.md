# OffTracker UX改善プラン：ペルソナと導線設計

## ペルソナ定義

### メインターゲットペルソナ
**名前**: 田中 太郎（30歳、ソフトウェアエンジニア）

**背景**:
- 常に時間を有効に使いたいと思っているが、実際は気が散って時間を浪費してしまう
- 「今日は絶対にXを終わらせる」と思って作業を始めるが、YouTubeを見たりDiscordで話したりして、結局終わらない
- 自分の行動パターンを理解して、効率化したいと思っている
- しかし、生産性ツールやタイマーアプリは「自分を監視される」感じが嫌いで続かない

**ニーズ**:
- 自分の行動を客観的に見たい
- なぜできなかったのかを理解したい
- 裁判される感じではなく、自分のパターンを理解したい
- 手軽に始められて、日常のワークフローに組み込みたい

**痛みポイント**:
- 「なぜ終わらなかったんだろう」と後悔するが、具体的な原因が分からない
- タイマーアプリは時間を計るだけで、なぜできなかったかは分からない
- 生産性スコアやランキングは「自分を評価される」感じが嫌い

**成功体験のビジョン**:
- Timelineを見て「ああ、ここでYouTubeを見てしまったんだ」と気づく
- Pattern画面を見て「難しい問題があると、調査に行ってそのまま終わるんだ」と自分のパターンを理解する
- 次回は「調査時間を15分に制限しよう」と具体的な改善策が思いつく

## 現在のUIの問題点

### 1. Home画面
**問題**:
- Idle状態とActive状態が同じ画面で切り替わるため、遷移が分かりにくい
- 「最近のセッション」が実際には動作していない（mockデータ）
- アクティブセッション中にTimelineに遷移する方法がない

**改善案**:
- アクティブセッション中に「Timelineを見る」ボタンを追加
- 「最近のセッション」を実際のデータから表示する
- 遷移を明確にする

### 2. Timeline画面
**問題**:
- セッション終了後に自動的に遷移しない
- 「結果を記録」ボタンが見つけにくい
- 現在のセッションか過去のセッションかが明確でない

**改善案**:
- セッション終了時に自動的にResult画面に遷移するオプション
- ボタンを大きく、目立つ位置に配置
- セッションの状態を明確に表示

### 3. Result画面
**問題**:
- 「振り返る」ボタンが右下にあり、見つけにくい
- 目標時間と実際の時間の比較が視覚的に分かりにくい
- 「できなかったこと」が必須項目になっているが、オプションにしたい

**改善案**:
- ボタンを中央、大きく配置
- 時間比較をバーで視覚化
- 「できなかったこと」をオプションにする

### 4. Reflection画面
**問題**:
- チェックボックスが多すぎて選ぶのが大変
- 「完了」ボタンが小さい
- 目的が表示されていない

**改善案**:
- チェックボックスをグループ化（技術的問題、時間的問題、他）
- ボタンを大きく配置
- 目的を表示して振り返りやすくする

### 5. Pattern画面
**問題**:
- コンテンツがほとんど表示されていない
- 「新しいセッションを開始」ボタンが目立たない
- パターン分析が動作していない

**改善案**:
- 過去のセッションをタイムライン形式で表示
- ボタンを大きく、目立つ配置
- ルールベースのパターン検出を実装

## 改善された導線

### 最適なユーザーフロー

```
1. Home画面（Idle状態）
   ├─ 目的を入力
   ├─ 目標時間を設定（オプション）
   └─ [作業を開始] クリック
       ↓

2. Home画面（Active状態）
   ├─ 目的・目標時間・開始時刻を表示
   ├─ 現在のアプリをリアルタイム表示
   ├─ 作業時間をリアルタイム表示
   ├─ [Timelineを見る] ← 新規追加
   └─ [作業を終了] クリック
       ↓

3. Timeline画面（セッション中）
   ├─ リアルタイムで行動を表示
   ├─ [作業を終了] ← 新規追加
   └─ [Homeに戻る]
       ↓

4. Result画面
   ├─ 目的を表示
   ├─ 目標時間 vs 実際の時間（バーで視覚化）
   ├─ 達成度を選択
   ├─ できたことを入力
   ├─ できなかったことを入力（オプション）
   └─ [振り返る] ← 大きく配置
       ↓

5. Reflection画面
   ├─ 目的を表示 ← 新規追加
   ├─ 原因を選択（グループ化）
   ├─ 自由入力
   └─ [完了] ← 大きく配置
       ↓

6. Pattern画面
   ├─ セッションのサマリー
   ├─ 過去のセッション一覧
   ├─ パターン分析（ルールベース）
   └─ [新しいセッションを開始] ← 大きく配置
       ↓

7. Home画面（Idle状態）に戻る
```

## ボタンの配置とスタイル

### ボタンの優先順位

1. **主要アクション**（大きく、目立つ色）
   - 作業を開始
   - 作業を終了
   - 振り返る
   - 完了
   - 新しいセッションを開始

2. **二次アクション**（中程度、グレー）
   - Timelineを見る
   - Homeに戻る
   - 戻る

3. **ナビゲーション**（小さく、青色）
   - 戻るリンク

### ボタンの配置

- **主要アクション**: 画面の中央、大きく
- **二次アクション**: 主要アクションの下、小さく
- **ナビゲーション**: ヘッダーの左、小さく

### ボタンの色

- **主要アクション**:
  - 緑: 前進するアクション（作業を開始、振り返る、完了、新しいセッション）
  - 赤: 停止するアクション（作業を終了）

- **二次アクション**: グレー

- **ナビゲーション**: 青
