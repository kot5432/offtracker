# Timeline画面調査結果

## 現在の実装

### 機能
1. **Timeline表示**: イベントをタイムライン形式で表示
2. **サマリー**: 総作業時間、アプリ切り替え回数、最長使用アプリ
3. **フィルター**: ネイティブアプリ、ブラウザ、アイドル時間のフィルター

### 表示内容
- アプリ名とサービス（例: Microsoft Edge/YouTube）
- 使用時間
- 切り替え回数

## ユーザーフィードバックに基づく問題

### ❌ 改善が必要な点

1. **インサイトがテンプレで変わらない**
   - 現在: 単にアプリの切り替えを表示
   - 欠如: 行動のパターンや傾向が見えない

2. **どのような行動をしていたのかの振り返りがわかりにくい**
   - 現在: アプリの使用時間と切り替えのみ
   - 欠如: 目的とのズレ、集中が途切れたポイントが見えない

3. **このアプリによって認識できたわけではない**
   - 現在: データを表示するだけ
   - 欠如: 分析やインサイトが提供されていない

## 改善案

### 方案1: 目的とのズレを視覚化
- 目的に関連するアプリ（例: VS Code for プログラミング）をハイライト
- 目的から離れたアプリ（例: YouTube）を警告色で表示
- 目的との関連度をスコア化

### 方案2: 行動のパターンを分析
- アプリ遷移のパターンを表示（例: VS Code → Google → YouTube）
- 脱線の頻度を表示
- 集中時間の分布を表示

### 方案3: 振り返りのヒントを提供
- 「YouTubeを長時間使用しているようです」
- 「集中が途切れたポイントを検出しました」
- 「VS Codeへの復帰率が低いです」

### 方案4: 集中が途切れたポイントを表示
- アプリ切り替えの頻度が高いポイントをマーク
- 長時間のブラウザ使用を警告
- 復帰に時間がかかったポイントを表示
