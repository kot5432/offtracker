# Phase 7.5-2: 6つの異なる状況で実使用検証

## 概要
OffTrackerを6つの異なる状況で実際に使用し、各状況での有効性を検証する。

## 検証目的
- 6つの異なる状況でOffTrackerを使用して、一貫して有効か確認
- パターン分析の必要性を確認
- Timelineの改善が必要か確認

## 検証シナリオ

### Session 1: プログラミング（YouTubeを見た）
- 目的: プログラミングをする
- 起きた状況: 途中でYouTubeを見た
- 期待: YouTubeが検出され、脱線が分かる

### Session 2: プログラミング（エラーで詰まった）
- 目的: プログラミングをする
- 起きた状況: エラーで詰まって検索した
- 期待: 検索時間が長いことが分かる

### Session 3: レポート（調査に時間がかかった）
- 目的: レポートを書く
- 起きた状況: 調査に時間がかかった
- 期待: 調査時間が長いことが分かる

### Session 4: 勉強（別の作業に移った）
- 目的: 勉強をする
- 起きた状況: 別の作業に移った
- 期待: 作業切り替えが多いことが分かる

### Session 5: 開発（予定より作業量が多かった）
- 目的: 開発をする
- 起きた状況: 予定より作業量が多かった
- 期待: 作業時間が長いことが分かる

### Session 6: 何かを完成させる（予定通り達成）
- 目的: 何かを完成させる
- 起きた状況: 予定通り達成できた
- 期待: 成功パターンが分かる

## 検証項目

### ① 行動を把握できたか
- Timelineで自分の行動が理解できたか

### ② 目的とのズレが分かったか
- 目的と実際の行動のズレが分かったか

### ③ 結果が分かったか
- 何が達成できなかったか分かったか

### ④ 「なぜ」が考えられたか
- 振り返りを通して「なぜできなかったか」を考えられたか

### ⑤ 振り返りは負担ではなかったか
- 振り返りを書くのが負担ではなかったか

### ⑥ 次の行動を考えられたか
- 次にどうするか考えるきっかけになったか

## 期待される発見

### 成功パターン
- どのような状況で成功するか
- 成功時の行動パターン

### 失敗パターン
- どのような状況で失敗するか
- 失敗時の行動パターン

### 改善点
- Timelineの改善が必要か
- インサイトが必要か
- パターン分析が必要か

## 次のステップ

- 6つのシナリオで実際に使用
- 各シナリオで検証テンプレートに記入
- 成功・失敗パターンを分析
- 改善点を特定
