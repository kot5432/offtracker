# ガントチャート実装プラン

## 目的
Timeline画面をガントチャート（横向きタイムライン）に変更して、時間の流れを客観的に見やすくする

## 現在の問題
- 縦型タイムラインは時間の流れが見にくい
- ユーザーがどのように行動していたかを振り返るのに不適切

## 実装方針

### 1. 横方向の時間軸を作成
- タイムラインコンテナの幅を固定
- 時間軸を横に表示
- 時間軸のラベルを追加

### 2. 各イベントを横方向に配置
- イベントの開始時間に基づいて横方向の位置を設定
- イベントの持続時間に基づいて幅を設定
- イベントを縦方向にずらして配置（重ならないように）

### 3. CSSの調整
- `.timeline`を横方向のコンテナに変更
- `.timeline-event`を絶対配置に変更
- `.timeline-axis`を時間軸として表示

## 実装手順

1. **timeline.htmlのCSSを変更**
   - `.timeline`を横方向のコンテナに変更
   - `.timeline-event`を絶対配置に変更
   - `.timeline-axis`を時間軸として表示

2. **renderGanttChart()を変更**
   - イベントを横方向に配置
   - 各イベントの位置を計算
   - 時間軸をレンダリング

3. **createGanttEvent()を変更**
   - イベントの横方向の位置を設定
   - イベントの幅を設定
   - イベントの縦方向の位置を設定

4. **renderAxisLabels()を追加**
   - 時間軸のラベルをレンダリング
   - 時間軸の目盛を表示

1. Timeline画面を開く
2. 疑似データをロード
3. ガントチャートが正しく表示されているか確認
4. 時間の流れが見やすいか確認
5. イベントが重ならずに表示されているか確認
