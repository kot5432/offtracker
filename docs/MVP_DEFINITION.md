# OffTracker MVP定義

## MVPの目的
ユーザーが実際に使ってフィードバックを得るための最小限の機能セット

---

## MVPの範囲

### 🎯 コア機能（必須）

#### 1. データ収集
- **アプリ名の取得** - 現在アクティブなアプリケーション名
- **使用時間の記録** - アプリごとの使用時間
- **ウィンドウ切り替え検知** - アプリ間の移動を記録
- **タイムスタンプ** - 各イベントの時刻

#### 2. データ表示
- **ガントチャート** - ウィンドウ切り替えの可視化
- **移動フロー** - どのアプリからどのアプリに移動したか
- **基本統計** - アプリ別使用時間のサマリー

#### 3. 基本的なUI
- **ダッシュボード** - 今日の使用状況表示
- **タイムライン** - ガントチャート形式の表示
- **設定画面** - データ収集のオン/オフ

### 🔲 MVPには含まない機能（今後の機能）

#### 高度な分析
- AIによる行動分析
- 目的との比較
- 脱線の詳細分析
- パーソナライズされた改善提案

#### 高度な機能
- 「見ていなさそう」の検知
- 自動セッション管理
- オフライン機能
- チーム機能
- モバイル対応

---

## MVPの技術要件

### データ収集（Rust）
```rust
// 必要な機能
- アクティブウィンドウの取得
- プロセス名の取得
- タイムスタンプの記録
- イベントのキュー管理
```

### データ保存
- **ローカルSQLite** - データの一時保存
- **Supabase同期** - クラウドへのデータ同期（オプション）

### UI（既存Webコード活用）
- **index.html** - そのまま使用
- **style.css** - そのまま使用
- **JavaScript** - Tauri APIとの通信を追加

## 推奨データ収集項目

### 📊 必須データ
| データ項目 | 説明 | 収集方法 |
|-----------|------|----------|
| アプリ名 | アプリケーションの実行ファイル名 | Windows API |
| ウィンドウタイトル | アクティブウィンドウのタイトル | Windows API |
| プロセスID | プロセスの一意識別子 | Windows API |
| タイムスタンプ | イベント発生時刻 | システム時刻 |
| イベントタイプ | ウィンドウ切り替え/フォーカス変更 | Windows API |

### 📈 将来的に追加すべきデータ
| データ項目 | 説明 | MVPでの扱い |
|-----------|------|-------------|
| アイドル時間 | 操作なしの時間 | ❌ 含まない |
| マウス/キーボードアクティビティ | 入力活動の有無 | ❌ 含まない |
| 画面内容 | スクリーンショット/テキスト | ❌ 含まない（プライバシー） |
| ネットワーク活動 | アクセスしたURLなど | ❌ 含まない（プライバシー） |
| システムリソース | CPU/メモリ使用率 | ❌ 含まない |

## MVPのアーキテクチャ

### システム構成
```
offtracker-desktop/
├── src-tauri/          # Rustバックエンド
│   ├── src/
│   │   ├── main.rs     # エントリーポイント
│   │   ├── window.rs   # ウィンドウ監視
│   │   ├── process.rs  # プロセス情報取得
│   │   └── storage.rs  # データ保存
│   └── Cargo.toml
└── src/                # Webフロントエンド
    ├── index.html      # 既存Web UI
    ├── style.css       # 既存スタイル
    └── app.js          # Tauri通信ロジック
```

### データフロー
```
Windows API
    ↓
Rust監視プロセス
    ↓
ローカルSQLite（一時保存）
    ↓
Tauri Commands
    ↓
Web UI表示
    ↓
Supabase同期（オプション）
```

## プライバシー考慮

### MVPでのプライバシー保護
- ❌ スクリーンショットを取らない
- ❌ キーロガーを記録しない
- ❌ ネットワークトラフィックを監視しない
- ✅ アプリ名とウィンドウタイトルのみ収集
- ✅ データはローカル保存が基本
- ✅ クラウド同期はオプション
